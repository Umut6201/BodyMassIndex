# Console BMI Calculator

A lightweight C# console application built to calculate Body Mass Index (BMI) and determine weight categories based on standard metrics. 

Designed with basic Object-Oriented Programming (OOP) principles to keep the calculation logic separated from the user interface.

---

## Features

- **Modular Architecture:** Uses a dedicated `BmiCalculator` class for calculation and classification rules.
- **Clean Input Parsing:** Reads weight (kg) and height (m) directly from user input.
- **Formatted Output:** Displays calculated BMI rounded to two decimal places along with the category status.

---

## BMI Categories

| BMI Range | Category |
| :--- | :--- |
| `< 18.5` | Underweight |
| `18.5 – 24.9` | Normal weight |
| `25.0 – 29.9` | Overweight |
| `>= 30.0` | Obese |
